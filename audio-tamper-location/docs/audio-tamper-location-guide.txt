Lab: audio-tamper-location

Noi dung:
- Tao audio mau cover.wav.
- Nhung chu ky fragile tamper-location vao tung block.
- Xac minh file chua bi sua.
- Tao file tampered.wav bang cach thay doi mot khoang thoi gian.
- Xac dinh block bi sua va khoang thoi gian nghi ngo.
- Chay checkwork de kiem tra 6 muc tien do.

Tep can quan tam:
- ~/stego/generate_cover.py
- ~/stego/mark_blocks.py
- ~/stego/verify_blocks.py
- ~/stego/tamper_audio.py
- ~/stego/cover.wav
- ~/stego/marked.wav
- ~/stego/tampered.wav

Cac lenh goi y:

cd ~/stego
python3 generate_cover.py --out cover.wav --seconds 5
python3 mark_blocks.py cover.wav marked.wav
python3 verify_blocks.py marked.wav
python3 tamper_audio.py marked.wav tampered.wav --start 3.20 --end 3.80
python3 verify_blocks.py tampered.wav

Giai thich ngan:
- tamper-location: file tu chua du lieu kiem tra cua chinh no.
- Fragile watermark: dau nhung rat de hong khi audio bi chinh sua.
- Block hash: moi block co hash rieng, giup khoanh vung loi.
- Tamper localization: khi block nao sai hash, ta doi block do sang moc thoi gian.

Checkwork:
- cover_created: da tao cover.wav.
- marked_created: da tao marked.wav.
- signature_found: verifier tim thay chu ky trong marked.wav.
- clean_audio_ok: marked.wav duoc xac minh la chua bi sua.
- tampered_created: da tao tampered.wav.
- tamper_localized: verifier khoanh vung duoc block bi sua.
